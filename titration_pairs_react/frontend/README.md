# Labster — фронтенд (лабораторная работа №5)

Одностраничное приложение на React + TypeScript + Vite + React-Bootstrap для гостя:
просмотр услуг — пар кислоты и щёлочи для титрования.

## Запуск

```shell
npm install
npm run dev     # http://localhost:3001
npm run build   # сборка в dist/
```

Запросы `/api/...` проксируются dev-сервером Vite на веб-сервис NestJS
`http://localhost:3000` (настройка `server.proxy` в `vite.config.ts`).
Если веб-сервис недоступен, данные карточек берутся из mock-коллекции
`src/modules/mock.ts`.

## Страницы приложения

Приложение отображается в портретном режиме — колонка шириной 430 px.

### Нижняя навигационная панель

Есть на всех страницах. Четыре пункта:

| Пункт | Состояние | Действие |
|---|---|---|
| Лента | доступен | переход на страницу «Лента» (`/feed`) |
| Добавление | недоступен | — |
| Плитка | доступен | переход на страницу «Плитка» (`/grid`) |
| Вход | недоступен | — |

Активный пункт выделяется белым жирным шрифтом.

### Лента — `/feed`, `/feed/:id`

Одна услуга на весь экран. Без `id` открывается первая услуга, с `id` — услуга с этим идентификатором.

- **Видео услуги** — автоматически проигрывается в вертикальной развёртке; если поле `video_url` пустое, проигрывается видео по умолчанию `public/DefaultVideo.mp4`.
- **Название услуги**.
- **Описание** — показывается первое предложение.
- **Кнопка «Ещё» / «Скрыть»** — раскрывает и сворачивает остальную часть описания.
- **Значение pH** и **концентрация (М)**.
- **Количество лайков** (❤️).
- **Кнопка «Следующий»** (стрелка) — переход к следующей услуге (`GET /api/titration_pairs/feed/:id?next=true`); на последней услуге ничего не происходит.

### Плитка — `/grid`

Список опубликованных услуг в 2 столбца.

- **Поле «Мин. концентрация»** — ползунок от 0 до 0,3 М с шагом 0,01; над ним выводится выбранное значение.
- **Кнопка «ОК»** — применяет фильтр: показываются услуги с концентрацией не меньше выбранной (`GET /api/titration_pairs?minConcentration=...`). По умолчанию отображаются все услуги.
- **Карточка услуги**: изображение (если поле `image_url` пустое — изображение по умолчанию `public/DefaultImage.jpg`), значение pH, название, концентрация, количество лайков.
- **Клик по карточке** — переход на страницу «Лента», начиная с этой услуги (`/feed/:id`).

## Структура

```
src/
  main.tsx                       точка входа, подключение Bootstrap
  App.tsx                        роутинг
  Routes.ts                      адреса страниц и подписи пунктов меню
  AppLayout.tsx                  оболочка: страница + нижняя навигация
  pages/FeedPage.tsx             страница «Лента»
  pages/GridPage.tsx             страница «Плитка»
  components/BottomNav.tsx       нижняя навигационная панель
  components/ConcentrationFilter.tsx  фильтр по концентрации
  components/TitrationCard.tsx   карточка услуги
  modules/titrationApi.ts        запросы к веб-сервису
  modules/mock.ts                mock-коллекция услуг
public/
  DefaultImage.jpg               изображение по умолчанию
  DefaultVideo.mp4               видео по умолчанию
```
